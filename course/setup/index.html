Setup and practice¶

What you need before you start, how to stay safe with data, and how to keep a simple evidence log.

What you need¶

  • A computer that can run Tableau Public
  • Permission to install software on it
  • A way to receive course files and submit your work

Before teaching starts

We will confirm operating systems, installation permissions, accessibility needs and the submission channel with everyone. No course data files are available yet.

Install Tableau Desktop Public Edition¶

This is the version we use for all lesson instructions.

  1. Open the official Tableau Public page.
  2. Check that your computer meets the listed requirements.
  3. Download and install Tableau Desktop Public Edition.

Before the first lesson, you will receive a small synthetic CSV file and a short smoke test. It asks you to:

  1. Open the CSV in Tableau.
  2. Check the data types of the fields.
  3. Create a simple sum.
  4. Save the workbook on your computer.
  5. Close it and open it again.

Exact menu steps will be added once they have been rehearsed on the course version of Tableau.

Keep your data safe¶

Anything you publish to Tableau Public is public

Published workbooks and their data can be seen by anyone. Hiding an item on your profile does not make it private, because it can still be reached through its link.

  • Use only the datasets supplied for this course.
  • Never upload private employer, customer or employee files.

Tableau Public lets you save workbooks on your own computer. Submitting a local workbook is an accepted course route, so publishing online is optional.

You can read more in Tableau's Public FAQ and saving guide.

If something does not work¶

Installation or internet trouble

Follow the demonstration or pair with a classmate, and keep writing your metric and checking notes. Complete your own workbook later, once access is back.

A browser-only version of Tableau may look different from the desktop instructions. It will only replace the desktop route once it has its own tested instructions.

Optional Python path¶

You do not need Python for the essential lessons.

Later, optional companions will show how the same Tableau ideas (selecting rows, grouping, distinct counts and date rules) look in pandas. Installation instructions will come with those notebooks once they are tested.

Keep an evidence log¶

For every task, write down a few short notes. They make your portfolio much easier to build.

Record Example prompt
Data release Which file and version did I use?
Question What decision is this for?
Grain What does one row represent?
Date window and filters Which records are included?
Metric definition What is the numerator and denominator?
Checks How did I confirm the number is right?
Chart and recommendation What should the stakeholder do next?

Save your workbook and your notes together.

Compare their populations and denominators before changing the chart.
