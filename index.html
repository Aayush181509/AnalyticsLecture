Data Analytics¶

Learn to turn a business question into a recommendation you can defend, using Python, clear charts and real analytical habits.

Welcome! I'm Aayush, your facilitator for this training programme.

We will explore and explain data from five areas of a business: retail and e-commerce, finance, operations, marketing and HR. Along the way you will also practise on sports, technology, government and other datasets.

This site is still being built

Right now you will find the Foundations section, the course roadmap and the first Python lessons. More lessons, cases and a Tableau section are on their way.

The business cases and the lesson template are previews. They are not ready-to-run assignments yet.

Course at a glance¶

  • Live, hands-on classes. Demonstrations, guided practice and independent work, plus practice between sessions.
  • Spreadsheet basics are enough. No coding experience is assumed. Lesson 0 starts from the very beginning.
  • Python in your browser. You run every lesson in Google Colab: nothing to install, and every result on these pages comes from the same code you run.
  • Synthetic and public data only. Never private workplace data.
  • Portfolio and briefing. You finish with a practical portfolio and an executive briefing grounded in checked evidence.
  • Tableau later. A separate Tableau section will show how to build the same analyses as interactive dashboards.

Where to start¶

Work through these pages in order:

  1. Foundations: why data analytics and clear presentation matter, with real examples.
  2. Learning roadmap: what each stage of the course covers.
  3. Setup and practice: getting started with Google Colab and keeping notes.
  4. Analytical workflow: the seven steps we use in every analysis.
  5. Business cases: the five business problems you will solve.
  6. Python Lesson 0: Python and Colab basics, then Lessons 1–4 on retail data.

How we will practise¶

Every topic follows the same rhythm:

  1. Watch a short demonstration.
  2. Run the working code yourself, step by step.
  3. Change a few lines to answer a related question on your own.
  4. Debug a deliberate mistake.
  5. Recommend an action to a stakeholder.

One habit to build from day one

Before you trust a chart, check three things: what each row means, how the metric is defined, and what evidence supports the number.

You will never be asked to write programs from scratch. Each lesson gives you working code to read, run and then modify. Instructor solutions are shared separately after each practice round.
