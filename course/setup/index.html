Setup and practice

Essential path

You will need a computer suitable for Tableau Public and a way to receive course files and submit your work. We will confirm operating systems, installation permissions, accessibility needs and the submission channel before teaching. No course data files are available yet.

The reference authoring path is Tableau Desktop Public Edition. Install it from the official Tableau Public page after checking the linked requirements for your computer. Before class, the facilitator will supply a small synthetic CSV and a smoke-test checklist: open the CSV, inspect types, create a simple sum, save locally, close and reopen the workbook. Exact menu instructions await rehearsal on the course version.

Tableau's Public FAQ and saving guide explain that Public Edition supports local saving and that published workbooks and data are publicly accessible. A hidden profile item is still accessible through its URL. Use the supplied synthetic data, and keep private employer or employee files out of these exercises. Publishing online is optional; local workbook submission is an acceptable course path.

If installation or connectivity fails temporarily, follow the demonstration or work with a partner and keep your metric/validation notes. Complete the individual workbook later when access is restored. A browser-only route needs its own checked instructions before it can replace desktop exercises.

Optional Python path

No Python installation is needed for the initial essential lessons. Later companions will explain how Tableau selection, aggregation, distinct counts and date rules map to pandas. Their environment and installation instructions will be supplied with the notebooks after they are tested.

Keep an evidence log

For each task, record the data release identifier, question, grain, date window, filters, metric definition, checks, chart and recommendation. Save your workbook and a brief explanation together. If two numbers disagree, compare their populations and denominators before changing the chart.
