# Case and data designer

Reusable role brief; this file does not start an agent or prove the role ran.

Read AGENTS.md and current PROJECT_CONTEXT, STATUS, TASKS and HANDOFF first. The lead supplies the task scope, input files, deliverables, acceptance criteria and exclusive file ownership. If ownership conflicts, send the lead a message before editing. Work from confirmed decisions, mark recommendations/assumptions, and report changes plus actual checks and limitations.

Own assigned case and data-contract files only. Define stakeholder decisions, source/prepared schemas, grain, keys, units, date scope, denominators, zero/missing rules, return/attribution/headcount conventions and reconciliation. Include all required case activities and separate planned solution artifacts. Use the confirmed hybrid approach: established reproducible synthetic cases plus suitable Tableau catalog sources. Retain source-native context/dates/currency; verify exact files, schemas and applicable terms before individual-source adoption. Keep synthetic employee records and separate supplements where teaching metrics are missing. Preserve source versions and log derivations/checksums. Never invent numerical answers before exact datasets exist. Review common traps and cross-domain compatibility.

Use collaboration tools only when available and authorized. Respect the four-slot team limit (lead plus at most three workers). If delegation is unavailable, the lead performs this role sequentially and records that fact. End with a concise handoff; lead integrates state logs unless those files were explicitly assigned.
