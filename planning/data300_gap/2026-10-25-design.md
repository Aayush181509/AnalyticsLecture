## Lecture notebooks

- Offline: load from `data/`, the NLTK setup cell from `planning/agents/china-notebook-author.md`, the CO₂ series from `statsmodels`.
- Teach well beyond Moodle: theory with intuition, worked examples on **non-graded** data (never the graded dataset's exact answers), "predict, then run" questions, misconceptions, a business case discussion, extra practice tasks with Core / Stretch / Challenge levels, a quiz, and a reading-packet link-back ("read Chapter n for …", no packet text reproduced).
- Each day's lectures fill that day's theory periods; a short instructor timing table goes in the notebook's last cell under "For the facilitator" (no answers).
- Executed by `scripts/run_notebooks.py` twice with identical SHA-256, converted with `.venv/bin/jupyter nbconvert --to markdown <nb> --output-dir=docs/data300/`.

## Guide pages (one per graded item)

Each guide, in our own words:

1. What the task is and which CLOs it serves; weight and deadline.
2. Route A — Try JupyterLab (as Moodle): the steps summarised, with the Moodle code referenced by part name, not reproduced.
3. Route B — offline: a local Anaconda code cell that loads the bundled data and otherwise follows the same steps (tested privately; outputs not shown).
4. Checks the student can make without seeing answers (row counts, totals that must reconcile, what a correct plot looks like).
5. Known pitfalls found in the Moodle instructions, with fixes. Known so far: Assignment 2 code says `for i in rangeNo:` (should be `range(n)`); Lab 6's Data Table input cells sit on another sheet (Excel needs them on the table's sheet) and the selection corner; Lab 4 `resample('ME')` needs pandas ≥ 2.2; Lab 7 Forecast Sheet needs a numeric or date timeline for `Q1-2023` labels; the capstone header `Colab_Multiplier`.
6. Beyond the lab: extra non-graded tasks for faster students.
7. Submission: file names, combining PDFs offline (this section's own setup page carries the advice), GAP drop-box.

No guide prints expected answers.
